# TestHub V2 UI 方案

## 1. 设计目标

- 看起来像平台，而不是功能集合
- 首屏要有“方向感”和“下一步”
- 同时服务负责人和执行人员
- 减少用户在多个模块中来回寻找入口

## 2. 信息架构

- 平台工作台
- 资产生产线
- 执行引擎
- 运营治理

## 3. 平台指挥台线框

```text
+-----------------------------------------------------------------------------------+
| 顶部标题区                                                                         |
| TestHub Platform Command Center                                                   |
| 本周重点 / 当前状态 / 主行动按钮                                                  |
+-----------------------------------------------------------------------------------+
| 关键指标                                                                           |
| [核心模块] [执行通道] [推荐起点] [平台成熟度]                                      |
+-----------------------------------------------------------------------------------+
| 三栏布局                                                                           |
| 左：角色视角                                                                       |
|   - 测试负责人今天看什么                                                           |
|   - 测试工程师今天做什么                                                           |
|                                                                                   |
| 中：交付流程                                                                       |
|   需求分析 -> 用例生成 -> 自动化执行 -> 报告回收                                   |
|                                                                                   |
| 右：优先建设建议                                                                   |
|   - 统一报告中心                                                                   |
|   - 统一调度入口                                                                   |
|   - 资产关联                                                                       |
+-----------------------------------------------------------------------------------+
| 模块矩阵                                                                           |
| [AI生成] [API测试] [UI自动化] [APP自动化] [数据工厂] [AI模式] [AI助手] [配置中心] |
+-----------------------------------------------------------------------------------+
| 发布路线图                                                                         |
| V2.1 统一入口 / V2.2 真实统计 / V2.3 交付闭环                                     |
+-----------------------------------------------------------------------------------+
```

## 4. 视觉方向

- 背景：浅色渐变，强调平台感和秩序感
- 主色：蓝绿双主色，传达专业、科技、稳定
- 卡片：圆角大卡片，适当玻璃态，但保证信息密度
- 字体层级：首屏强标题 + 中密度说明 + 清晰模块标签

## 5. 关键交互

- 首页直接进入平台级入口
- 支持从指挥台进入每个模块
- 提供“本周重点”和“推荐路径”而不是只列菜单
- 对负责人和执行者分别给出行动建议

## 6. 首批实现页面

- 首页：品牌入口与模块总览
- 平台指挥台：真正的平台级工作台
- 全局外壳：补齐平台工作台导航

## 7. 后续增强

- 接入真实统计卡片
- 支持角色切换视图
- 支持版本维度的质量看板
- 支持任务/风险提醒
