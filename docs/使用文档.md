## 1. 平台简介

TestHub 是一个 AI 驱动的智能测试管理平台，帮助测试团队：

- 🤖 **AI 自动生成测试用例** — 输入需求，AI 自动生成完整测试用例
- 📋 **用例全生命周期管理** — 创建、评审、导入、导出、执行
- 🔍 **多维度筛选** — 按模块、优先级、类型、版本筛选用例
- 📊 **执行追踪** — 记录每次执行的结果和历史
- 🔧 **丰富工具集** — 数据工厂、API 测试、UI 自动化

## 12. 常见问题

### Q: AI 生成的用例质量不高怎么办？

**A:** 尝试以下方法：
1. 在 Prompt 配置中调整提示词
2. 提供更详细的需求描述
3. 使用澄清对话功能，让 AI 充分理解需求
4. 尝试更换 AI 模型（不同模型擅长不同场景）

### Q: 批量导入时中文乱码？

**A:**
1. Excel 文件保存时选择 `.xlsx` 格式（不要 `.xls`）
2. CSV 文件使用 UTF-8 编码保存
3. 系统会自动处理 UTF-8-BOM 编码

### Q: 浏览器看不到最新数据？

**A:** 可能是浏览器缓存，尝试：
1. `Ctrl + Shift + R` 硬刷新
2. 或 F12 → Network → 勾选 Disable cache → 刷新

### Q: 批量导入失败？

**A:** 检查：
1. 文件格式是否为 `.xlsx` 或 `.csv`
2. 是否有「标题」和「预期结果」列（必填）
3. 是否安装了 openpyxl：`pip install openpyxl`

### Q: AI 澄清对话中 AI 不提问？

**A:** 使用的是 Clarifier Prompt V3，AI 会主动提 3-8 个问题。如果仍不提问，可能是：
1. 需求描述过于简单 → 补充更多细节
2. AI 模型配置问题 → 检查 API Key 和模型名称
