# TestHub 蓝盾流水线配置说明

流水线固定构建分支：`user/nn-uicase-auto`

## 代码库

- 代码库类型：GitLab
- 仓库地址：`http://git.leigod.top/root/nn-uicase-auto.git`
- 分支：`user/nn-uicase-auto`
- 凭据：在蓝盾凭据管理中新增 GitLab HTTPS 凭据，用户名填写 GitLab 用户名，密码填写 Access Token。令牌只保存到蓝盾凭据，不写入仓库、脚本或流水线日志。

## 构建节点

选择已有的 Windows 节点：`wl-windows10`（`10.1.2.213`）。节点需要提供：

- Python 3.12 或更高版本
- Node.js 20 或更高版本
- npm
- 可访问 GitLab 仓库和依赖源的网络

## 构建步骤

代码拉取完成后，在仓库根目录添加一个 Windows PowerShell 构建步骤：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\blueking_ci.ps1
```

调试 AI 用例时，仅执行前 3 条 Web 用例：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\blueking_ci.ps1 -Stage web -SkipInstall -WebCaseLimit 3 -SkipArticles
```

指定某几条 Web 用例调试：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\blueking_ci.ps1 -Stage web -SkipInstall -WebCaseIds '101,102,103'
```

`-Stage web` 只选择 `execution_target=web` 或 `dual` 的用例，并使用 Web 任务描述，不会执行 Windows 用例。完整 Web 回归使用 `-WebCaseLimit 0`；Windows 回归脚本仍需单独调用，不会被该阶段隐式触发。

脚本会按顺序执行：

1. 安装 `requirements.txt` 中的后端依赖。
2. 执行 `python manage.py check`。
3. 执行 UI 自动化和 API 测试相关的稳定单测，并生成 `ci-artifacts/backend-junit.xml`。
4. 在 `frontend` 目录执行 `npm ci` 和 `npm run build`。
5. 生成 `ci-artifacts/ci-summary.json`。

## 产物归档

在蓝盾的产物归档步骤中配置：

```text
ci-artifacts/**
frontend/dist/**
```

## 注意事项

- 蓝盾构建使用的是 `user/nn-uicase-auto`，不会构建 `master`。
- 流水线不依赖开发机的 `.env`，也不会把数据库密码、AI Key 或 GitLab Token 写入日志。
- 当前脚本执行的是不依赖真实浏览器、NN 客户端、MySQL 数据和外部账号的稳定单测；真实环境回归应单独配置测试数据库和目标客户端。
